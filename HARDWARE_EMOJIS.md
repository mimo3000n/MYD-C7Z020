# 🛠️ Hardware Documentation Emoji Reference

### 💡 Quick Tips for GitHub
1.  **Spacing:** Always put a single space between the emoji and your text (e.g., `# ⚡ Power`).
2.  **Anchors:** GitHub ignores emojis in header links. 
    * **Header:** `# 🔌 Connectivity` 
    * **Link:** `[Go to Connectivity](#connectivity)`
3.  **Compatibility:** These work on GitHub, GitLab, and Bitbucket.
