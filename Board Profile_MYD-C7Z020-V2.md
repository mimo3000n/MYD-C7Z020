# 📋 Board Profile: MYIR MYD-C7Z010/20-V2

The MYD-C7Z010/20-V2 typically uses an onboard **USB-to-UART/JTAG** chip (often a Silicon Labs CP2105 or an FTDI chip). To use OpenOCD, you need to point to the correct interface.

### 1. Makefile Constants for MYD-C7Z010/20
Update these variables in your `Makefile`:

```make
# --- MYIR Board Configuration ---
# Use the Z7010 or Z7020 depending on your specific module
DEVICE       = xc7z010clg400-1 
# OR: DEVICE = xc7z020clg400-1

# Interface: Most MYIR boards use a standard FT2232 or CP2105. 
# If using an external Digilent JTAG HS2 cable:
BOARD_CFG    = interface/ftdi/digilent-hs2.cfg

# Target: Specific to Zynq-7000 series
TARGET_CFG   = target/zynq_7000.cfg

# nextpnr Chip Database (Ensure this path exists in your install)
CHIPDB       = /usr/share/nextpnr/xilinx-chipdb/xc7z010.bin
```

---

### 2. OpenOCD Programming Script
The Zynq-7000 requires a slightly different initialization sequence because the ARM cores and the FPGA share the JTAG chain.

**Update your `load` target in the Makefile to this:**

```make
load: $(TARGET).bit
	sudo openocd -f $(BOARD_CFG) -f $(TARGET_CFG) \
		-c "init; pld load 0 $<; exit"
```

### 3. "Blinky" Test Files
To verify your toolchain is working, create these two files and run `make load`.

#### `top.v` (Verilog Source)
The MYD-C7Z010-V2 has a system LED. We will create a simple counter to blink it.
```verilog
module top (
    input  wire clk,    // 50MHz Clock from PS or Oscillator
    output wire led     // Green LED
);
    reg [24:0] counter;

    always @(posedge clk) begin
        counter <= counter + 1;
    end

    assign led = counter[24]; // Blinks approx. every 0.6 seconds at 50MHz
endmodule
```

#### `constraints.xdc` (Physical Constraints)
*Note: Pin locations may vary slightly based on your specific MYIR baseboard version. Consult your MYIR schematic for "JP1" or "LED" pins.*
```text
# Clock - Adjust pin 'N18' to your board's oscillator input
set_property PACKAGE_PIN N18 [get_ports clk]
set_property IOSTANDARD LVCMOS33 [get_ports clk]

# LED - Adjust pin 'P14' to your board's user LED
set_property PACKAGE_PIN P14 [get_ports led]
set_property IOSTANDARD LVCMOS33 [get_ports led]
```

### 4. Important: The "PS-PL" Dependency
On Zynq boards like the MYIR, the FPGA clock (`FCLK_CLK0`) is often generated by the **ARM Processing System (PS)**. 

**The Challenge:** If the ARM cores aren't initialized (via an FSBL or U-Boot), the clock to the FPGA might be "off," and your blinky won't blink.

**The Fix:**
1.  Boot the board into Linux or U-Boot first (using an SD card).
2.  Once the board is at a prompt, run your `make load` command from WSL2. 
3.  The PS will have already initialized the clocks, allowing your PL (FPGA) logic to run immediately.

### 5. Summary Checklist for MYIR Board
1.  **USBIPD:** `usbipd attach --wsl --busid <ID>` (Windows).
2.  **Synthesis:** `yosys -p "synth_xilinx -top top -json top.json" top.v` (WSL2).
3.  **P&R:** `nextpnr-xilinx --json top.json --xdc constraints.xdc --fasm top.fasm` (WSL2).
4.  **Bitstream:** `fasm2bels --device xc7z010clg400-1 --fasm top.fasm --bit top.bit` (WSL2).
5.  **Program:** `make load` (WSL2).
